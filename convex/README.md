# Bimi backend

Convex owns the database, realtime API, Evolution webhooks, jobs, assistant orchestration, and provider calls.

Start with the [project setup](../README.md), [architecture](../docs/architecture.md), and [provider guide](../docs/ai-providers.md). Read `_generated/ai/guidelines.md` before editing functions.

Use `npx convex dev` with your own deployment to develop and regenerate API declarations. Run `bun run test` and `bun run typecheck` from the repository root.
